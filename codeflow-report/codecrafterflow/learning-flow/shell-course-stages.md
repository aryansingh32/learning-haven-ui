# Learning Flow: Shell Course Stages

The curriculum deconstructs the complex process of building a shell into **30+ modular stages** across logical themes, framing difficulty progressively.

## Stage Breakdown

* **Base (Getting Started)**
  * Print a prompt (`VERY EASY`)
  * Handle invalid commands (`EASY`)
  * REPL (`EASY`)
  * exit (`EASY`)
  * echo (`EASY`)
  * type (`EASY`)
  * Locate executable (`MEDIUM`)
  * Run program (`MEDIUM`)

* **Navigation**
  * pwd (`EASY`)
  * cd: Absolute paths (`MEDIUM`)
  * cd: Relative paths (`MEDIUM`)
  * cd: Home directory (`MEDIUM`)

* **Quoting**
  * Single quotes (`MEDIUM`)
  * Double quotes (`MEDIUM`)
  * Backslash outside quotes (`MEDIUM`)
  * Backslash within single quotes (`MEDIUM`)
  * Backslash within double quotes (`MEDIUM`)
  * Executing a quoted executable (`MEDIUM`)

* **Redirection**
  * Redirect stdout (`MEDIUM`)
  * Redirect stderr (`MEDIUM`)
  * Append stdout (`MEDIUM`)
  * Append stderr (`MEDIUM`)

* **Command Completion**
  * Builtin completion (`MEDIUM`)
  * Completion with arguments (`MEDIUM`)
  * Missing completions (`EASY`)
  * Executable completion (`MEDIUM`)
  * Multiple completions (`HARD`)
  * Partial completions (`HARD`)

* **Filename Completion**
  * File completion (`MEDIUM`)
  * Nested file completion (`MEDIUM`)
  * Directory completion (`EASY`)

* **Programmable Completion**
  * Register complete builtin (`EASY`)
  * Printing missing specifications (`EASY`)
  * Displaying registered specifications (`MEDIUM`)
  * Single completion (`MEDIUM`)
  * Handling no completions (`EASY`)
  * Passing command-line arguments (`EASY`)
  * Passing environment variables (`EASY`)
  * Multiple completer candidates (`EASY`)
  * Longest common prefix (`MEDIUM`)
  * Unregister a completion (`EASY`)

* **Background Jobs & Pipelines**
  * The jobs builtin (`EASY`)
  * Starting background jobs (`MEDIUM`)
  * ... (and more)
  * Dual-command pipeline (`HARD`)
  * Pipelines with built-ins (`HARD`)
  * Multi-command pipelines (`HARD`)

* **History & Expansion**
  * The history builtin (`EASY`)
  * ...
  * The declare builtin (`EASY`)
  * Expanding variables (`HARD`)
