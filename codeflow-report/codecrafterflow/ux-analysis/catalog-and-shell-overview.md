# UX & Psychology Analysis: Catalog and Shell Overview Page

## Onboarding & Urgency Mechanisms
* **Onboarding Alert Banner**: A blue informational banner at the top reads: "New here? Start here to learn how challenges work." This is a low-friction entry point for first-time visitors.
* **Conversion Pill (Urgency)**: A prominent countdown pill in the navbar reads "22 hours left" with a yellow border, injecting urgency to prompt membership activation.

## Discoverability Mechanics
* Free projects (e.g., *Build your own Shell*) display a bright green "FREE THIS MONTH" badge with an arrow indicating immediate start. 
* Paid courses feature lock icons alongside their total stage count (e.g., *Build your own Redis - 115 stages*), giving immediate clarity on what is open vs. behind a membership without gating the content of the catalog itself.

## Motivation Psychology & Onboarding Flow
* **Removing Paywall Friction**: The course overview prominently features a green-bordered card proclaiming: "Build your own Shell is free this May. The core challenge experience is completely free this month." This encourages high-intent developer sign-ups who want to master shell programming without immediately pulling out a credit card.
* **Value-First Upselling**: Within the free promotional box, the platform seeds premium value: "If you'd like to enjoy advanced features such as running turbo tests or unlimited code examples, you'll need a membership." This clarifies the exact value of upgrading without gating the core learning experience.

## Trust & Social Validation Mechanisms
* **Real-time Live attempts (FOMO)**: The right-hand sidebar lists active attempts by developers (usernames, chosen languages, and visual progress bars).
* **Live WebSockets**: The sidebar is not static; it receives live updates as users compile and pass stages worldwide, creating an immersive, busy developer community environment.
* **High-Credibility Social Proof**: Testimonials from automation/senior developers at **Apple** and **CenturyLink** are displayed above the footer, validating the high engineering quality.
